# Contributing to NC <->

Thank you for your interest in contributing to NC! We welcome community contributions to help improve this project.

## Getting Started <->

Before you begin, please review the project documentation in the `/docs` directory to understand what NC is and how it works.

We also expect all contributors to abide by our [Code of Conduct](CODE_OF_CONDUCT.md) to ensure a welcoming and inclusive environment for everyone.

## How to Contribute <->

### 1. Prepare Your Branch <->
1. Fork the repository and clone it to your local machine.
2. Create a feature branch off of `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Keep it atomic:** Ensure your Pull Request (PR) focuses on fixing a single issue or adding a single feature. Smaller PRs are significantly easier and faster to review.

### 2. Test Your Changes <->
* Ensure your code builds locally without any errors.
* Run the existing test suite to ensure no regressions are introduced.
* Add new tests if you are introducing new logic or fixing a bug.

### 3. Open a Pull Request <->
1. Push your branch to your forked repository.
2. Navigate to the original repository and click **"New Pull Request"**.
3. Fill out the PR template completely, explaining *what* you changed and *why*.

## Next Steps <->

Once your PR is submitted, a maintainer will review your code. We may suggest some changes or ask for clarification before merging it into `main`. Thank you for your time and effort!
