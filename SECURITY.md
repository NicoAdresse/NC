# Security Policy <->

## Supported Versions <->

Only the current initial release is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.1   | :white_check_mark: |
| < 0.0.1 | :x:                |

## Reporting a Vulnerability <->

If you discover a security vulnerability within this project, please report it responsibly.

* **Preferred Method:** Use GitHub's private vulnerability reporting feature under the repository's **Security** tab to ensure disclosure remains confidential.
* **What to Include:** Please provide a clear description of the issue, steps to reproduce, and the potential impact.
* **Response Timeline:** You can expect an initial acknowledgment within 48 hours. Once the report is verified, a patch or mitigation strategy will be worked on for future releases.

Please avoid opening public issues for unpatched security vulnerabilities.
